# Game Booster

PC optimizer for gaming, written in Python with a graphical interface.

## What it does
- Cleans temporary system files (cache)
- Closes background processes (Chrome, Discord)
- Frees RAM to improve performance

## Built with
- Python 3
- Tkinter (graphical interface)
- PyInstaller (compiled to .exe)

## How it works
1. Open the program
2. Press the **OPTIMIZAR** (optimize) button
3. Wait for the confirmation message
4. Launch your game
